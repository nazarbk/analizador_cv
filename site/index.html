Privacidad

Tu CV es tuyo: el análisis gratis no sale de tu navegador

Un CV tiene tu nombre, tu teléfono, tu email y tu historial laboral. Por eso el análisis gratuito se hace con código que se ejecuta en tu propio navegador: el archivo no se envía, no se guarda y desaparece al cerrar la página.

Solo si compras el Informe Pro, y después de aceptarlo, se envía el texto de tu CV (sin tu nombre ni tus datos de contacto) y la oferta a la API de IA de Anthropic para generarlo. Esta web no lo guarda.

No hay cuentas, cookies, publicidad ni analítica. Las librerías que leen los PDF y los Word se sirven desde esta misma web, así que tu navegador no se conecta a terceros. Si quieres retomar el trabajo otro día, puedes activar el guardado en tu propio navegador; está desactivado por defecto.

Preguntas

Lo que conviene saber antes de empezar

¿Qué es un ATS y por qué importa?

Un ATS (sistema de seguimiento de candidaturas) es el software que usan muchas empresas para recibir, leer y filtrar los CV. Si convierte mal tu documento, por ejemplo mezclando columnas o perdiendo tu email, tu candidatura puede quedar incompleta o fuera del filtro antes de que la vea una persona.

¿Es gratis?

El análisis completo, los datos para copiar y el CV en formato ATS son gratis y sin registro. Solo es de pago el Informe Pro (4,99 €, pago único): tu CV reescrito para una oferta concreta, la carta de presentación y el encaje requisito a requisito.

¿Guardáis mi CV o lo usáis para algo?

No. El archivo se procesa en tu navegador y no llega a ningún servidor. Solo si activas «Guardar mi trabajo» se guarda en el almacenamiento de tu propio navegador, y puedes borrarlo cuando quieras.

¿Garantiza que pase cualquier filtro?

No. Cada empresa configura su ATS de forma distinta, así que ninguna herramienta puede garantizarlo. El análisis aplica las buenas prácticas más extendidas y te dice qué mejorar y por qué; los resultados son orientativos.

¿Usa inteligencia artificial?

El análisis gratuito no: funciona por reglas dentro de tu navegador. El Informe Pro sí usa IA generativa (la API de Anthropic) para reescribir tu CV y redactar la carta, y solo si lo compras y lo aceptas expresamente; se envía el texto del CV sin tu nombre ni tus datos de contacto, y no se guarda en esta web. Según sus condiciones comerciales, Anthropic no usa los datos enviados por su API para entrenar sus modelos.

¿Puedo generar mi CV en inglés?

Sí. Crea la versión en inglés desde «Datos para copiar»: idiomas, fechas, lugares y titulaciones habituales se traducen solos, y el resto se marca para que lo traduzcas tú o con el traductor que prefieras.

¿Qué formatos admite?

PDF con texto seleccionable, Word (.docx), OpenDocument (.odt) y texto plano. Si tu PDF es una imagen escaneada, no tiene texto que leer: expórtalo de nuevo desde el editor original o pega el texto.

¿Lo puede usar una empresa para filtrar candidatos?

No está pensado para eso. Es para que cada persona revise su propio CV. Usarlo para puntuar o descartar candidaturas de terceros lo convertiría en un sistema de alto riesgo según el Reglamento europeo de IA, y los términos de uso lo prohíben.
